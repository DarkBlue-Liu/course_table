## 荣耀手机安装与功能验收（2026-11-06更新）

请先选择验证路径：如果还要测试应用内下载、断网重试和取消安装，先走下一节的局域网路径，不要先安装正式候选5。若只验证本次新增功能，可按以下步骤直接覆盖安装。已安装5后不要降级到验收基线4；后续更新测试需准备更高版本或使用独立测试设备。

1. 在手机现有App中导出课程JSON，分享到应用外；截图记录课程、颜色、开学/放假日期、节次时间、主题、提醒开关及提前分钟数。JSON不包含主题和提醒偏好。
2. 将电脑上的 `build/release-1.3/course-table-1.3.0.apk` 通过USB或文件传输工具传到手机。仓库文档中的电脑本地路径不能作为手机网络下载链接，APK也不会随源码推送自动成为Release附件。
3. 在手机文件管理器打开APK，按系统提示允许该来源安装，选择“更新”。不要卸载旧版；若提示签名冲突或要求先卸载，立即停止并反馈完整提示。
4. 在“设置→版本与更新”确认版本是 `1.3.0(5)`。已有学期的老用户不应再次强制进入教程。核对原课程、颜色、学期日期、节次时间、主题和提醒设置。
5. 新建测试课程，确认14种颜色均可选；选新增颜色保存。从最近任务中划掉App再打开，确认课程及颜色仍在。
6. 在周课表空白格点一次，应只显示“＋”；再点“＋”进入原添加页，核对预填星期和节次，并尝试修改。默认周次仍为第1周到学期末、全部周；取消新建不应产生课程。
7. 左上角切换周／日视图，分别选有课、无课及跨周日期。编辑一门测试课程后，两种视图应显示同一份修改结果；单双周规则保持一致。
8. 设置中重看教程并返回，确认原学期日期与偏好未改变。首次用户教程不要通过卸载主用App来测试，应使用模拟器或备用测试设备。
9. 反馈手机型号、系统版本、当前App版本，以及上述各项是否通过；失败时提供操作步骤和完整提示。当前没有收到本次1.3荣耀手机验收反馈，不将这些项目标记为通过。

## 局域网测试与Windows 11步骤

1. 不卸载手机现有正式版；先导出课程JSON到应用外，并截图主题、提醒及学期日期。
2. 运行 `powershell -ExecutionPolicy Bypass -File scripts/build-lan-acceptance.ps1`。脚本读取pubspec候选版本5，构建私有Debug基线4并用正式密钥签名，输出 `build/lan-packages/course-table-lan.apk`。该包可覆盖正式1.2(4)，但只限私测；若手机已装正式5，勿用基线4降级。
3. 运行 `powershell -ExecutionPolicy Bypass -File scripts/build-release.ps1` 构建正式候选5；不设置UPDATE_MANIFEST_URL时线上入口为空。
4. 电脑连接自己手机热点，运行 `ipconfig` 获取WLAN IPv4。不要依赖文档或APK旧预填地址，也不要把不可信公共Wi-Fi设为专用网络。
5. 在项目根目录运行（替换实际IP）：
```powershell
powershell -ExecutionPolicy Bypass -File scripts/serve-update.ps1 -ComputerIP 192.168.122.99
```
服务使用Python 3.11+的HTTP/1.1，仅读取build/lan-update。元数据默认从pubspec读取，APK大小和SHA256自动计算；不公开项目根目录、密码或JKS。
6. 手机浏览器打开 `http://实际IP:8765/version.json`，再下载 `http://实际IP:8765/course-table-lan.apk` 安装验收包。进入设置→版本与更新，填写同一个实际version.json地址。
7. 如Windows防火墙阻挡，管理员终端只放行WLAN接口、当前电脑IP、手机热点网关IP和8765端口。可用 `Get-NetRoute -InterfaceAlias WLAN -DestinationPrefix '0.0.0.0/0'` 获取手机网关；保留Public类别也能设置精确规则，不关闭整个防火墙。测试后删除该临时规则。
8. 检查说明、下载进度；测试取消下载、断网恢复重试。首次允许App安装来源后，返回再点击安装。先取消一次系统安装，验证当前课程可用，再确认更新到1.3.0(5)。比较课程、颜色、日期、主题及提醒。
9. 关闭测试服务器（前台Ctrl+C），移除临时防火墙规则。

正式版由Manifest禁止明文流量，Dart也拒绝HTTP和HTTPS→HTTP重定向。线上地址通过 `--dart-define=UPDATE_MANIFEST_URL=https://自己的稳定入口/version.json` 配置，APK下载地址由JSON中的apkUrl提供。当前未购买、开通或接入真实托管，不能将线上更新标为完成。
